# Machine-Learning-Project
ML Final Group Project

### Project Purpose
The purpose of this project is to utilize machine learning to determine if there is any correlation between a Pokemon's base stats and their typing.

### Repository Structure
```text
Machine-Leaning-Project/
├── benchmark.ipynb
├── EDA.ipynb
├── import_database.py
├── pokemon_data.json

├── README.md

```

### Setup Instructions
There is no external setup required for this notebook, other than installing the dependencies in requirements.txt.

### Data Access Instructions
Data is available from the pokemon_data.json file.

### Notebook Sequence
For the notebook sequences, simply run all the cells in order.
